# Ideas Hub 

Ideas-Hub is a **project showcase and management dashboard** that allows users to add, edit, delete, pin, and track projects in a clean, organized table-based interface. It also supports sharing project ideas with others. Built with **HTML, Tailwind CSS, and vanilla JavaScript**, ProjectPulse is perfect for students, developers, or teams looking to manage ideas efficiently.

---

## 🔹 Features

### **Your Projects**
- Add projects with **title, description, category (Current/Past/Future), and status (Planned/In Progress/Completed)**.
- **Edit or delete** existing projects (protected by secret key).
- **Pin important projects** to keep them at the top of the table.
- **Search and filter** projects by title, description, or category.
- Color-coded table rows for easy category recognition:
  - Current → Blue  
  - Past → Gray  
  - Future → Green
- Status column to track project progress.
- Hover effects on action buttons for better UX.

### **Shared Projects**
- Share project ideas with optional “Submitted By” field.
- Edit or delete shared projects (protected by secret key).
- Clean table view of all shared ideas.

### **Security**
- Secret key verification for editing, deleting, and pinning projects to prevent unauthorized changes.

### **Data Persistence**
- Projects are stored in **localStorage**, so your data persists even after closing the browser.

---

## 🔹 How to Use

1. **Open the dashboard** in your browser.
2. Navigate between **Your Projects** and **Shared Projects** using the tabs.
3. **Add a new project** by filling in the fields and clicking **Add Project**.
4. **Edit, delete, or pin** a project using the action buttons.
5. Use the **search bar and category filter** to find projects quickly.
6. Share your project ideas in the **Shared Projects** section.
